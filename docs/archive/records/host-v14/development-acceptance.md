SRP：协调器拥有请求，窗口/工作区拥有关闭许可，设置服务拥有文件操作准入，Program 拥有退出交接。OCP：菜单与看板复用窄端口，启动差异集中在描述对象。LSP：普通退出、取消、文档修订、命令排空和资源保留继续走原链。ISP：UI、设置冻结和交接三个小接口只提供实际需要的方法。DIP：UI 不操作 Process；系统等待与启动在助手边界，测试用窄委托替换，不解析已释放 Provider。

没有引入通用状态机、事件总线、服务定位器或热卸载框架。采用类、方法、许可和明确所有权；中文注释集中解释提交点、取消后保留实例、最终关闭不可恢复、命令排空、超时、身份验证和设置冻结竞态。SDK public API、包版本和数据 schema 没有修改。

相较计划的具体落地：启动解析合并进 `HostLaunchSpecification`；无需另建 Resolver 接口。Abort 以关闭一次性管道表示，不设长期标记。最终信号名为 CleanExit。超时常量为 15/90 秒，协议内核接受 CancellationToken，单元测试用明确取消验证，不另建时间框架。

## 自动化与证据层级

- `HostRestartTests`：共享请求、重复点击、可撤销设置冻结、在途失败/取消、普通关闭、启动参数及身份字节协议。
- `HostRestartHandoffTests`：最终许可缺失/错误、父进程退出码、取消等待、创建失败不重试、未知版本、父进程身份错误/自身、重复许可只启动一次。
- `HostRestartLifecycleTests`：真实关闭结果的释放顺序、资源保留、Provider 失败与幂等；结合原生命周期测试验证清理边界。
- `HostRestartUiTests`：真实菜单投影与 MainWindow、助手准备期间释放自身命令租约、最终否决时保留两份 Document 的引用身份、助手失败恢复及迟到 continuation 防护。
- `HostRestartProcessTests`：隔离目录复制测试 Harness 和真实 MyPlugTest，执行生产 `Program.Run`、HostRuntime、窗口关闭、助手和后继启动；仅替换 Avalonia 平台为 Headless，以及错误窗口为测试收据。看板使用实际 XAML 按钮的 Command。该层是真实 OS 进程验证，不是原生桌面体验验证。
- 原有 `DocumentCloseTests`、操作/命令/工作流关闭门、布局失败与窗口归属、插件开关保存/关闭和加载测试继续进入完整 verify，不通过修改历史断言跳过回归。

两种启动形式均使用中文/空格目录和含引号、`&`、`$()` 的参数；三次 Host 的独立 PID、启动时间、退出码、参数、工作目录、数据根及当前禁用状态可从收据交叉核对。每个 Host 已持有真实布局 Writer 锁，测试另行独占打开必须失败；全部退出后测试能独占打开同一锁。第一轮通过功能中心额外打开一个欢迎 Document，后继仅有各自默认欢迎页，证明未重开上轮页面。

取消与无许可退出不产生后继。故障注入的退出码 0 不代替 CleanExit；强杀只针对测试持有的旧进程。延迟退出用明确文件信号在最终许可确认后阻塞旧进程返回，验证助手不会提前拉起，再放行并验证后继初始化。所有进程均登记身份；正常收据写入测试输出目录，失败清理仅针对本夹具创建的进程与临时目录。

取消/退出等待超时和新进程创建失败由确定性协议单元测试覆盖；真实跨进程覆盖管道断开及许可后等待。没有在系统上强造 PID 复用，也没有等足生产 90 秒才能判定超时。原生错误窗口的可见性仍属下节人工范围，不以替换后的错误收据冒充桌面通过。

## 修正与验证记录

开发中发现并修正了：Headless 最终 Closing 故障注入时机、关闭后通知覆盖取消收据、新增命令的菜单与命令面板完整断言、xUnit 异步分析器违规。补充文档测试时区分了默认欢迎页与跨启动重开，增加非空 Document 身份断言及真实参数往返。中间失败报告保留在 artifacts，不改写为通过。

基线和最终完整 verify 都是开发门禁，包含固定补丁、locked restore、Release 零警告构建、各层测试、契约/API 比较及真实 ZIP 验收。没有修改 Gate 执行逻辑、发布政策或 API 基线；测试侧 Avalonia.Headless 沿用现有固定版本并纳入中央包与 lock 文件，不成为生产 Host 依赖。
