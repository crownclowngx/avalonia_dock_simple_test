# 工作区搜索与功能入口（V8 / V16 / V18）

> 用途：当前使用或开发指南；状态：当前。核对日期：2026-09-21。版本与支持范围见[集中基线](../reference/platform-baseline.md)，实现依据见本文对应源码或验收链接。

> V18 已实现四类分组、动作提示和命令目标核对。设计取舍见[归档方案](../archive/plans/host-v18-command-palette-interaction-plan.md)，自动验证和实机体验边界见[开发记录](../archive/records/host-v18/development-acceptance.md)及[专用验证](../maintenance/host-v18-command-palette-verification.md)。

欢迎页“开始使用”和“文件 → 功能中心…”打开同一个功能选择窗口。选择功能，点击“打开”，即可在新标签中开始工作。已有插件目录仍可从工具中心显示。

按 `Ctrl+Shift+P` 打开命令面板，可以一次搜索四类结果：

| 分组 | 名称左侧 | 执行效果 |
| --- | --- | --- |
| 已打开的页面 | ↩ | 回到原实例，保留内容和未保存修改 |
| 新开页面 | ＋ | 用该入口的新建意图打开一个独立页面 |
| 工具面板 | 显示／展开／定位 | 隐藏时显示，自动收起时展开，停靠或浮窗时定位原工具 |
| 命令 | 保留原动作名称 | 沿用菜单和快捷键的共享执行路径 |

功能与已有页面可能同名，分别出现在“新开页面”和“已打开的页面”组。页面名称旁显示本次运行的序号和当前页标记，下方显示来源与说明；底部预告当前选择按 Enter 的效果。序号不随筛选变化，关闭后不复用；它不是文件编号，也不会跨启动恢复。长文本可省略，完整目标保留在提示和可访问名称中。

仍然只有一个搜索框和一份连续列表。组标题不占选择项，无需先选类别；上下键直接跨组，右侧仅保留有效快捷键。同名的不同实例、来源及创建意图各自保留。

## 新标签的位置

从主窗口或文档浮窗按 `Ctrl+Shift+P` 新建，页面进入发起窗口在面板打开前的活动文档组。焦点在工具上时使用同窗最近有效的文档组。纯工具浮窗没有文档区，则回到主窗口最近活动或默认文档组。

初始化期间切换到另一窗口不改变本次落点。原分组已移除或移到其他窗口时，先尝试原窗口内其他有效文档组；来源窗口已关闭、正在关闭或没有有效组时回退主窗口。无法安全发布时，面板保留查询并显示失败。异步完成后的焦点恢复不会撤销用户后来的切窗、切页或新面板会话。

已有页面搜索只激活原实例和承载窗口；工具和普通命令沿用既有规则。功能中心、欢迎页、插件目录及文件打开/恢复入口保留原有主文档区策略。本轮不改变这些入口的默认落点。开发范围见 [V16 记录](../archive/records/host-v16/development-acceptance.md)；Host 整体人工验收见[所有者确认](../archive/records/host/manual-acceptance-20260920.md)。

## 查询与键盘

名称精确匹配优先，其后依次是名称前缀、名称包含、说明／分类／来源等辅助字段包含。查询忽略首尾空白和英文大小写；不做拼音、模糊纠错或使用频率预测。无查询时组序为页面、创建入口、工具、命令。有查询时，按每组最好的匹配等级排组，平局采用固定组序；组内按匹配等级、同等级可用项优先、名称和真实身份排序。一个组的其余匹配行留在组内，避免已有页面与同名新建入口穿插。

输入后默认选择第一个可执行结果；全部禁用时选择第一条并显示原因；无结果时清空选择和底部效果。状态刷新保留原身份、顺序和滚动位置。方向键选择，Enter 或双击正文执行；禁用项可选中阅读说明，但不会执行或偷偷转交另一项。目标消失时本次执行立即终止，刷新并提示，补选项需新的 Enter 才执行。Esc 关闭空闲面板并恢复原焦点。中文预编辑期间，Enter、方向键和 Esc 留给输入控件；原生输入法实机验收状态见开发记录。

功能初始化期间，面板显示“正在打开功能…”，禁用重复提交；Esc 和主窗口关闭不会冒充取消。成功后关闭面板并聚焦目标内容；失败保留查询、选择和本次错误，可以原地重试。普通命令继续采用原来的关闭面板后执行时序。

执行会重新核对可用性。插件已不可用、页面已关闭或处于关闭等待时，旧结果不再执行，也不会按名称改选其他页面。搜索、排序和图标显示不初始化插件页面。

当前页面命令显示“作用于：标题 · 页面序号”。保存也属于页面命令；提交时校验页面身份和上下文代次，展示后切页的旧提交会拒绝，刷新后可再次执行。打开文件、帮助和功能中心等全局入口不绑定页面。插件命令保留原名称，例如“打开小说项目”仍作用于当前页，“预览导出”不承诺导出完成。插件仅提供布尔可用状态时显示“当前状态下不可用”；工具和 Host 已知原因直接显示真实说明。

## 工具的隐藏与恢复

“工具 → 插件看板…”打开独立的版本、兼容矩阵与诊断窗口；命令面板搜索“插件看板”或“插件状态”均可找到同一入口。操作和状态含义见[插件看板](plugin-status.md)。

工具标题栏 × 表示“隐藏工具”。在“工具 → 工具中心…”中点击“显示”即可恢复原实例；工具隐藏期间后台服务可继续运行。页面标签 × 仍关闭页面，未保存内容继续经过保存确认。

工具中心每行提供星标、显示／定位与“⋯”菜单；分类分配、隐藏和常用排序放在更多菜单中。“整理工具”集中管理分类及隐藏全工作区工具。工具中心的搜索跨导航分类，但保留显式来源；“清除来源”只解除来源限制。

浮窗中的页面定位会激活实际承载窗口，最小化时先恢复。命令面板在调用窗口显示并保持工作台唯一会话。布局保存只记忆工具空间安排；业务文件仍需通过支持保存的页面执行 `Ctrl+S`。V11 继续不跨启动恢复 Document；工具位置和分组使用 [Layout V3](../reference/dock-layout-snapshot-v3.md)。
