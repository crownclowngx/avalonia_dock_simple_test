# 工作区搜索与功能入口（V8）

欢迎页“开始使用”和“文件 → 功能中心…”打开同一个功能选择窗口。选择功能，点击“打开”，即可在新标签中开始工作。已有插件目录仍可从工具中心显示。

按 `Ctrl+Shift+P` 打开命令面板，可以一次搜索四类结果：

| 结果 | 右侧动作 | 执行效果 |
| --- | --- | --- |
| 功能创建入口 | 打开新标签 | 用该入口的新建意图打开一个独立页面 |
| 本次运行已打开页面 | 切换到页面 | 定位原实例，保留内容和未保存修改 |
| 辅助工具 | 显示／定位 | 恢复工具或激活已有工具、展开自动收起区域 |
| 已声明可发现的工作台命令 | 执行命令 | 沿用菜单和快捷键的上下文与执行规则 |

功能与已有页面可能同名，右侧动作说明区分“新建”与“切换”。同名页面的说明中还显示功能、来源和本次运行的页面序号。序号在本次运行内不随筛选变化，关闭后不复用；它不是文件编号，也不会跨启动恢复。

## 查询与键盘

名称精确匹配优先，其后依次是名称前缀、名称包含、说明／分类／来源等辅助字段包含。查询忽略首尾空白和英文大小写；不做拼音、模糊纠错或使用频率预测。无查询时按页面、功能、工具、命令排列，同等级按名称和真实身份稳定排序。

输入会选择新的首项；状态刷新优先保留原身份，目标移除后选择仍存在的首项。方向键选择，Enter 或双击执行。禁用项说明当前不可执行，不会跳过它偷偷执行另一项。Esc 关闭空闲面板并恢复原焦点。

功能初始化期间，面板显示“正在打开功能…”，禁用重复提交；Esc 和主窗口关闭不会冒充取消。成功后关闭面板并聚焦目标内容；失败保留查询、选择和本次错误，可以原地重试。普通命令继续采用原来的关闭面板后执行时序。

执行会重新核对可用性。插件已不可用、页面已关闭或处于关闭等待时，旧结果不再执行，也不会按名称改选其他页面。搜索、排序和图标显示不初始化插件页面。

## 工具的隐藏与恢复

工具标题栏 × 表示“隐藏工具”。在“工具 → 工具中心…”中点击“显示”即可恢复原实例；工具隐藏期间后台服务可继续运行。页面标签 × 仍关闭页面，未保存内容继续经过保存确认。

工具中心每行提供星标、显示／定位与“⋯”菜单；分类分配、隐藏和常用排序放在更多菜单中。“整理工具”集中管理分类及隐藏全工作区工具。工具中心的搜索跨导航分类，但保留显式来源；“清除来源”只解除来源限制。

布局保存只记忆空间安排；业务文件仍需通过支持保存的页面执行 `Ctrl+S`。V8 没有增加跨启动页面会话恢复，也没有改动 SDK 或持久化格式。
