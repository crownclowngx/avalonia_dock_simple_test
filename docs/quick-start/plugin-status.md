# 插件看板

> 用途：当前工作树使用指南；核对日期：2026-09-19。V13 插件开关已接入，尚未公开发布。版本与支持范围见[集中基线](../reference/platform-baseline.md)。

通过 **工具 → 插件看板…** 打开，也可以按 `Ctrl+Shift+P` 搜索“插件看板”或旧名称“插件状态”。窗口可以调整大小，保持打开时仍能操作主工作区；重复打开恢复并激活同一个窗口，`Esc` 关闭。没有插件或活动文档时入口仍可使用。

## 插件启用与禁用（重启生效）

在左侧选择插件，进入右侧 **概览 → 插件启用设置 → 下次启动启用**。切换后立即保存，出现“已保存”才表示成功；完整退出并重新启动 Host 后生效。当前会话中的页面和后台任务继续运行。

存在待生效设置时，可点击顶部 **重启并应用更改…**，自动完成关闭和再次启动。它应用全部已保存设置，不限于当前选中或筛选出的插件。未保存文档仍会先询问，取消则保留工作区；准备期间开关与重读暂不可用。没有配置变化时也可从 **文件 → 重新启动 Host…** 发起。具体步骤见[重启指南](restart-host.md)。

本次启用、下次禁用显示“待禁用”；本次禁用、下次启用显示“待启用”。改回本次启动设置会清除待重启。禁用项保留在列表，可以再次启用；重新启用仍需经过兼容和初始化检查。

保存失败会恢复已确认的选择并显示原因。若其他实例更改文件，点击“重新读取设置”取得最新意图后再操作；普通刷新不自动读取外部修改。配置错误、身份不完整、保存中或退出中，开关不可操作并显示原因。

未加载插件的“检查安装产物”只检查磁盘文件，明确提示“本次未加载”；历史通过报告不会改变禁用状态。配置及恢复规则见[插件开关契约](../reference/plugin-enablement.md)。

## 三个页签

左侧保留本次会话发现的插件，包括已禁用、加载失败、没有完整身份的候选。搜索支持插件 ID、程序集、版本、状态和错误码；全部、可用、异常、已禁用、待重启筛选与搜索同时生效，刷新保留仍存在的选择。

矩阵默认显示当前 Host 列；未检查身份时，首列只作最新历史参考。勾选“展开历史构建”查看其他列。矩阵内可按匹配当前、存在失败、有未执行、不匹配 / 待检查或无报告筛选，筛选依据是已显示列的最新结果。

| 页签 | 查看内容 |
| --- | --- |
| 概览 | Host 环境、插件业务版本和声明 SDK 范围、产物摘要、构建依赖及固定处理建议 |
| 兼容矩阵 | 行是具体插件产物，列是具体 Host 构建与环境；每格分别显示各验收层级。宽矩阵可横向滚动，悬停查看构建与环境详情 |
| 详情与诊断 | 所选插件的每份报告及分项、时间、来源，再列本次会话状态、贡献和已脱敏诊断 |

顶部计数来自本次 Host 会话。可用插件也可能有警告，因此“可用”和“异常 / 警告”不是互斥分类。历史通过报告不能覆盖当前加载或初始化失败。

## 状态与证据操作

- **刷新状态**：读取本次会话的最新运行状态。打开和重新激活窗口也会刷新；不重新加载插件。
- **检查安装产物**：在后台读取文件和内容摘要、核对已加载托管程序集身份，并重新读取报告。概览显示检查时间。后续文件变化需要再次检查，窗口不持续监控安装目录。
- **导入报告…**：选择维护者提供的 `compatibility-report.json`。相同内容重复导入不增加记录；同 ID 不同内容拒绝覆盖。导入后先显示历史参考，再点击检查以确认适用性。
- **复制诊断信息 / 导出摘要…**：取得所选插件的受控状态与验收摘要。导出为文本，不含导入报告的任意正文或个人安装路径。

界面读取失败时保留上次成功结果和时间，并显示错误。关闭窗口取消自己的读取任务，不停止插件后台服务；取消主窗口关闭也不会销毁看板。

## 怎样判断结果

“匹配当前产物与环境”表示报告的插件文件、Host 文件、规则及运行环境与本次检查一致，不代表报告来源经过认证。静态、加载与组合、Workspace、业务与真机分别显示，不能用一个层级通过替代其他层级。

| 状态 | 含义与下一步 |
| --- | --- |
| 无报告 | 没有这份产物的离线验收证据；不等于不能运行 |
| 未执行 | 报告没有执行这个层级或场景；需要时补验 |
| 失败 / 执行中断 | 查详情及维护者保留的 TRX、日志；中断不能记为通过 |
| 待检查产物身份 | 尚未检查或无法取得身份；先执行文件检查 |
| 其他插件产物 / Host 构建 / 运行环境，或规则已变化 | 该报告属于其他条件，只作历史参考 |
| 历史结果不同 | 显示最新报告并提示历史差异；详情保留所有记录，不挑选一次成功掩盖失败 |
| 安装内容已变化 | 当前会话仍使用已加载内容；按原安装流程重启 Host 后再检查 |

旧插件没有 `plugin.build.json` 时，编译 NuGet 版本显示未知。程序集引用版本单独显示，不能用它推测包版本。SDK 声明范围也不是“已验证范围”。

报告保存在 Host 数据根的 `compatibility/reports`；随 Host 分发的 `CompatibilityReports` 目录只读发现。看板不修改插件目录，不安装、更新、即时启停或热卸载插件，也不执行报告正文中的命令或地址。

## 旧布局

原“插件状态”Dock Tool 已退役，看板是独立窗口，不进入工具中心或布局。当前 Layout V3 合并和工具偏好继续精确排除已退役内置 ID，保留其他工具与暂时缺失插件的记录；旧 V1/V2 布局文件不读取或迁移。
