# 插件状态窗口

通过 **工具 → 插件状态…** 打开，也可以按 `Ctrl+Shift+P` 搜索“插件状态”。
窗口可调整大小，保持打开时仍能操作主工作区；重复打开会恢复并激活同一个窗口，`Esc` 关闭。
即使所有工具均已隐藏、没有活动文档或没有插件，入口仍可使用。

## 查看状态

顶部显示本次会话已发现的插件数量、当前可用数量，以及存在异常或警告的数量。
“异常 / 警告”包含加载失败、生命周期失败和已有警告/错误记录；可用插件也可能有警告，
因此这些计数不是互斥分类。等待初始化、正常停止不自动算作故障。

- 搜索支持插件 ID、程序集、版本、状态说明和错误码，忽略英文大小写及首尾空格。
- 筛选提供全部、可用、异常，搜索与筛选同时生效。异常和警告项优先显示。
- 左侧选择插件，右侧查看基本信息、已声明的文档/工具/命令/工作流动作以及按时间排列的诊断记录。
- 未读取到 Plugin ID 的失败候选以目录名称显示；取得身份后会把同一候选的多个阶段合并展示。
- “已声明”表示插件提交过相应贡献；“插件可用”表示当前插件门控开放，具体命令是否可执行仍取决于活动文档等上下文。
- 点击“复制诊断信息”复制所选插件的状态和已脱敏记录；也可以直接选择详情文字复制。

## 刷新含义

打开、重新激活窗口，以及点击“刷新”时，读取本次 Host 会话的最新状态。刷新保留当前搜索、筛选和仍存在的选择。
页面底部显示最近一次成功读取的时间；读取失败时保留旧结果，并显示失败提示。

刷新不会扫描安装目录、重新加载插件或重启后台任务。安装文件发生变化后，按现有插件安装流程重启宿主。
窗口未打开时没有专门的轮询或状态订阅；关闭窗口不停止插件服务。

## 从旧版本升级

原“插件状态”Dock Tool 已退役，不再出现在工具中心、Dock 标签或工具类命令入口中。
旧布局会定向移除它及原“工具管理”的记录，保留其他工具的位置、显隐、固定状态和 Pane 比例。
首次写回前保留原始布局到 `layout-v2.json.<GUID>.pre-tool-retirement.bak`。

工具中心会清理这两个退役项的收藏、最近使用、分类分配和历史名称；正常的自定义分类保留。
其他暂时缺失插件的历史偏好继续保留，不会被误清理。插件状态窗口本身不写入 Dock 布局。
