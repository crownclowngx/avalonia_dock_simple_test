# 工作台启动与插件加载

> 用途：解释 V15 启动窗口。核对日期：2026-09-20。适用于包含本次改动的 Host；当前安装版是否更新以部署记录为准。

打开程序后先看到羽毛启动窗口。它会显示正在扫描、加载、注册或初始化插件，以及当前插件的标识；插件准备完成后自动打开工作台。

“本阶段已处理 X / N 项”是当前阶段的处理数量。切换阶段后计数会重新开始，失败和跳过会有相应文字；它不是剩余时间，也不表示所有插件均已成功加载。很快完成的启动不会为了播放动画额外等待。

部分插件失败时，宿主按既有规则继续启动可用功能。主窗口顶部会留下提示，点击“查看插件看板”查询诊断。无法继续的启动会显示错误窗口，可以复制诊断和定位日志。

点击启动窗口的关闭按钮会请求停止启动。界面显示“正在停止启动”期间正在等待当前操作安全收尾，之后不会再弹出主窗口。某些同步插件操作无法立刻取消，关闭请求不等同于强制结束进程。

Windows 会遵守系统的客户区动画设置；也可以在启动程序的环境中设置 `MYAVALONIA_REDUCED_MOTION=1`，让羽毛保持静止。文字与真实进度仍然显示。
