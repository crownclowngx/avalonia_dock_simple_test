# 重新启动 Host

> 用途：当前工作树 V14 使用指南；日期：2026-09-19。安装目录尚未随本轮开发更新。

选择 **文件 → 重新启动 Host…**，也可以在 `Ctrl+Shift+P` 命令面板搜索“重新启动 Host”。无需先手工关闭所有页面，也无需退出后再手工打开程序。

在 **工具 → 插件看板…** 修改“下次启动启用”，等出现“已保存”后，可点击 **重启并应用更改…**。它应用全部已保存的待生效设置；不局限于当前选中的插件。

## 点击后会发生什么

1. 显示“正在准备重启…”。正在保存的插件设置会先完成，此时不能重复请求或修改开关。
2. 未保存的文档仍按正常关闭流程询问保存、放弃或取消。选择取消、取消另存路径或保存失败时，原工作区继续保留。
3. 保存最终工具布局后，窗口短暂关闭，再自动出现新的 Host。新的会话读取最新启动设置。

上次打开的 Document 不自动重开；默认欢迎页仍会显示。需要保留的文档内容请保存到文件，下次按正常方式打开。工具布局、显隐及收藏沿用已有恢复规则，用户文件和业务数据不会被删除。

## 取消与失败

准备失败会在原窗口显示原因，可以处理保存问题或文件占用后重试。已成功保存的内容不会因取消重启而回滚。

若原窗口已关闭但自动启动失败，会出现“Host 自动重启未完成”的独立提示和诊断位置。确认原 Host 已退出，再手工打开工作台；不要删除文档、布局或插件配置来强行修复。

启用插件仍需通过原有兼容与初始化检查。新 Host 自身启动失败时沿用启动错误提示，不会不断自动重启。插件后台任务由其原生命周期收尾，不会跨进程自动续跑。
