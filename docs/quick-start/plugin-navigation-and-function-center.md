# 插件目录双模式与功能中心使用说明

> Host V6 改造；保留现有插件、Document 和布局身份。V6 是改造顺序，产品与 SDK 不随此名称升版。

## 1. 在原 Tool 内切换目录

“插件分组菜单”顶部增加“显示方式”选择框：

| 模式 | 展示与操作 |
| --- | --- |
| 旧版（平铺） | 按完整分类字符串分组，展开后单击功能创建文档，沿用统一四宫格图标 |
| 新版（树形） | 按 `/` 展开多级分类，分类旁显示全部后代创建入口数，单击叶子创建文档 |

第一次使用默认旧版，主动切换后保存选择，下次启动恢复。切换保留当前 Tool 的停靠位置和已打开的文档。
两套目录分别保留本次运行内的展开状态；展开状态不跨启动保存。

## 2. 文件 → 新建文档…

该入口打开功能中心，重复打开会激活同一个选择窗口。

1. 在左侧选择分类，右侧列出该分类及全部子分类的功能；“全部功能”返回总目录。
2. 输入搜索词，在全部分类中搜索名称、说明和分类路径。标题会显示“全部分类中的搜索结果”。
3. 清空搜索恢复先前分类；点击分类会退出搜索并显示该分类。
4. 选中功能后点击“创建”、按 Enter 或双击列表项，创建成功后关闭弹窗并激活新文档。

浏览和搜索只读元数据，不创建插件页面。失败时保留窗口、搜索和选择，并显示本次错误，可以原地重试。
取消按钮或 Esc 关闭空闲选择窗口；创建期间禁用重复提交和关闭，等待已有创建完成。
Host 退出时还会等待在途文档操作，超过宽限沿用资源保留策略，避免初始化中释放插件依赖。

功能中心独立于 Tool 的展示模式，选择旧版时也可使用。

## 3. 插件如何提供多级分类

继续使用现有 `DocumentDescriptor.MenuCategory` 字符串，无需新增 SDK 字段：

```csharp
menuCategory: "闲才业务工具/文本检测"
```

```text
闲才业务工具
  文本检测
    Excel 批量审核
    审核结果分析
    文本智能审核
```

- `/` 是固定分隔符，段首尾空格会去掉，分类名称区分大小写。
- `-` 保留字面含义：`大唐-会计` 仍是一个分类。
- `A//B`、`/A`、`A/` 等包含空段的非法路径整体回退为一个原始名称，入口不会丢失，并记录一次诊断。
- 相同完整路径合并；同名但不同父级的分类独立。一个分类可以同时含子分类和直属功能。
- 计数按创建入口计算：一个 Document 的多个创建意图分别显示、分别计数。
- 旧版始终显示完整原始字符串，例如 `闲才业务工具/文本检测` 仍为一个平铺分组。

本轮未修改外部插件。原本只写“闲才业务工具”的三个 Document 仍在一级分类；需后续修改它们的元数据才会出现“文本检测”层级。

## 4. 无需 PNG 的公共矢量图标

新版树和功能中心使用 Avalonia `PathIcon`/`Geometry` 绘制 Host 内置图形，通过既有 `IconPath` 引用固定名称：

```csharp
iconPath: "builtin:table"
```

| 名称 | 图形用途 |
| --- | --- |
| `builtin:module` | 公共默认四宫格 |
| `builtin:folder` | 分类文件夹 |
| `builtin:table` | 表格、批量数据 |
| `builtin:chart` | 统计分析 |
| `builtin:text-check` | 文本审核 |
| `builtin:image` | 图片 |
| `builtin:video` | 视频 |
| `builtin:download` | 下载 |

解析顺序为创建意图图标 → Document 图标 → 公共默认图标。创建意图缺省时继承 Document；最终非空值若不在上述目录中，直接用默认图标，不继续猜测。
名称大小写须一致。空值、未知名称、文件路径、URL 和其他格式都使用默认图标；此功能不加载外部图片或网络资源。
矢量随主题与控件尺寸绘制，同一个图形可以同时出现在多个位置，各位置有独立控件。

## 5. 自定义“旧版/新版”的名称

退出 Host 后编辑导航偏好文件，下次启动生效：

```text
%LOCALAPPDATA%/MyAvaloniaManagement/v2/plugin-navigation-v1.json
```

如果设置了 `MYAVALONIA_DATA_DIRECTORY`，文件直接位于该完整目录下，不再追加产品名或 `v2`。

```json
{
  "schemaVersion": 1,
  "pluginMenuMode": "tree",
  "modeDisplayNames": {
    "legacy": "经典目录",
    "tree": "业务树"
  }
}
```

只需修改 `modeDisplayNames` 的文字。内部模式固定为 `legacy` 和 `tree`，显示名不参与身份判断。
空白名称使用默认值；未知模式回退旧版；损坏 JSON 或未知 schema 会保留 `.invalid.bak` 备份并回退。
偏好保存失败不会阻止本次切换，只影响下次启动的记忆。本轮没有运行时改名编辑器。
