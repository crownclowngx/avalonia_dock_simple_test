# 浮动窗口与布局恢复

> 用途：Host V11 使用指南。状态：实现已接入，真实桌面与外部原生控件验收单独跟踪；核对日期：2026-09-16。数据细节见 [Layout V3 契约](../reference/dock-layout-snapshot-v3.md)。

## 浮动与回停

拖出 Document 标签或 Tool 标题可创建浮窗，也可使用 Dock 的浮动菜单。整组浮动移动组内内容，主窗口的中心文档停靠区继续保留。把鼠标拖入可接收分组的内容区域，看到整区高亮后松开即可回停，无须精确命中中央小按钮。目标已有标签时合并到该组，空组则填满区域；浮动和回停复用原模型、View 与文档 Scope。

需要分屏时，将鼠标移到上、下、左、右的具体按钮；外侧全局方向按钮继续有效。标签栏仍按原方式排序或插入。悬停只显示预览，松开才处理；离开可接收区域或取消拖动不会执行默认合并。区域回停的原生遮挡和多屏体验仍在[专项验收](../maintenance/dock-area-fill-verification.md)中单独跟踪。

工具浮窗内可分组与分割。自动隐藏边栏属于主窗口：工具浮动后不能自动隐藏，回停后重新可用。内容全屏期间先退出全屏，再进行浮动、回停或重置布局。

将 Tool 放到另一个 Tool 的上方或下方，会在目标工具区域内排列，周围布局保持原位。浮窗内部也采用局部分割。将 Tool 放到主窗口文档区（包括已拆分的文档子组）的上方或下方，继续使用横跨工作区的全宽工具区域；外侧全局停靠提示保持原有行为。这些分组和比例会随工具布局保存，重启无需重置旧布局。

浮窗使用与主窗口相同的命令和快捷键；`Ctrl+S` 保存当前文档，`Ctrl+Shift+P` 在调用窗口打开命令面板。同一时刻只有一个工作台命令面板。页面列表和工具中心激活目标时会激活实际承载窗口，目标最小化时先恢复窗口。

## 关闭行为

| 操作 | 结果 |
| --- | --- |
| 关闭工具，所在浮窗还有其他内容 | 只隐藏该工具，保留其他工具和文档 |
| 关闭最后一个 Tool，或关闭整个工具浮窗 | 获准后隐藏工具并关闭窗口外壳，保留实例、原位置及分组 |
| 在工具菜单或工具中心隐藏最后一个浮动 Tool | 同样先处理窗口关闭；取消时保留工具、活动项和窗口 |
| 从工具中心重新显示工具 | 回到原组；只显示指定工具，其他隐藏工具继续隐藏 |
| 关闭文档浮窗 | 汇总该窗文档的保存选择，等待命令结束后再关闭 |
| 取消或文档保存失败 | 保留整组页面和工具，恢复命令入口 |
| 关闭主窗口 | 处理所有窗口的文档，保存最终布局后关闭浮窗并进入原有 Runtime 退出流程 |

V11-P2 修复了工具浮窗右上角关闭后留下黑框的问题。标题栏按钮、工具菜单和工具中心统一遵守关闭许可；取消关闭不会先清空工具。关闭后的隐藏布局记录仍会保留，重启时不会因此创建空白窗口。

## 重启时记住什么

记住工具的窗口位置、正常尺寸、最大化意图、分组、分割比例、显隐、主窗自动隐藏状态和活动工具。最小化状态不在重启时恢复。

Document 可以在本次运行中浮动，重启不会自动重开。布局文件不保存文档路径、标题、页面身份或内容，纯文档浮窗也不保存。文档内容仍需使用保存命令写入业务文件。

暂时缺少或不可用的插件，其工具布局记录继续保留；只显示当前可用内容，不生成空白浮窗。插件下次可用时按保留记录恢复。

## 找回与重置

“视图 → 找回屏幕外浮窗”把标题区域不可达的浮窗校正到当前屏幕工作区。启动和屏幕变化也会校正位置；负坐标本身合法，常见于主屏左侧的显示器。

“视图 → 重置布局…”会先确认，再把工具恢复默认隐藏状态，并将浮动文档移回主窗口。已打开文档及其未保存修改仍保留。取消确认不会修改布局；应用过程中原生窗口拒绝关闭时恢复原运行树，已关闭的旧窗口重建展示外壳，业务实例保持不变。

## 自动保存与旧文件

连续调整会合并，在最后一次变化约 750 毫秒后保存。退出前会提交最后一份完整布局，关闭窗口产生的隐藏通知不会覆盖它。

| 文件 | 用途 |
| --- | --- |
| `layout-v3.json` | 当前工具布局 |
| `layout-v3.json.bak` | 上一份有效布局 |
| `layout-v3.lock` | 写入句柄的载体；文件存在不表示仍被占用 |
| `layout-v3*.invalid.bak` | 损坏输入的保留副本 |
| `layout-v2.json` | 首次升级时只读转换，原字节不变 |

默认目录仍为 `%LOCALAPPDATA%\MyAvaloniaManagement\v2\`。`MYAVALONIA_DATA_DIRECTORY` 表示完整数据根。V1 文件不读取、不迁移、不改写。

同一数据根只允许一个实例写入。第二实例及识别到未来布局版本的实例会显示只读提示，本次布局调整不保存，也不会在第一实例退出后自动接管。

保存失败时主窗口显示提示，可使用“重试保存布局”。失败不会改动文档保存结果，上一有效布局继续保留；最终布局保存失败时窗口保持打开，以便重试或处理文件占用。
