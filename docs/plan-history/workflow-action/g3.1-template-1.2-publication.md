# Workflow Action G3.1：Templates 1.2.0 发布补充记录

## 范围变更

G3.1 原始范围明确不修改或发布 Templates。SDK 发布完成后，发布操作者于 2026-08-26 明确扩大范围，
要求把通用模板同步到公开 SDK 3.2.0 基线并强制上传。因此本记录作为 G3.1 的后续补充，不改写原始
候选范围，也不把 Build、Host 产品或业务插件纳入发布。

Templates 从 `1.1.0` 提升到 `1.2.0`。生成项目精确使用 Core/UI SDK `[3.2.0]`，manifest SDK 区间为
`[3.2.0, 4.0.0)`，Build 继续精确使用已发布的 `1.1.2`。模板保持通用 Document 示例，不加入
Workflow Studio、Runner 或其他业务专用代码；项目内 Workflow 文档说明可选 Workflow SDK `1.0.0`。

不再调用冻结在 SDK 3.1.0 的历史 G0/G1 脚本。每轮先在本轮隔离 NuGet 缓存执行全仓 locked restore，
避免复用已经清理的临时包路径。

## 上传与公开源复验

NuGet.org 在上传前确认 `1.2.0` 未占用，随后接受冻结候选并返回 `Created`。上传输出同时提示包未内嵌
license 元数据；这不影响上传成功，但 NuGet 版本不可覆盖，因此 `1.2.0` 保持与已上传字节完全一致，
后续版本应先补 `PackageLicenseExpression` 再打包。

公开索引完成后，使用全新 NuGet 缓存和模板 hive 从纯 NuGet.org 安装 `1.2.0`，生成
`PublicTemplateProbe` 并完成 locked restore、Release 0 警告/0 错误构建、1/1 测试和插件打包。
