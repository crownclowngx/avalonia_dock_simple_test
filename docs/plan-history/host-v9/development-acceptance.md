## SOLID 与设计约束

- Dock 适配仍留在 Host internal 边界，不向插件 SDK 暴露新 Dock 类型。
- 指针保护只负责指针所有权和结束后的恢复，不接管 Dock 排序/停靠决策。
- 回收器负责缓存与安全挂载；View 租约、Document Scope 和 Session 保持既有唯一所有者。
- 优先修改现有窄边界和补充行为测试，不为升级引入通用框架、全局单例或多余接口。
