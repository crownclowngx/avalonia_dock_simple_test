# 插件兼容证据契约

> 状态：V10 开发中；日期：2026-09-16。尚未正式发布。实施范围见 [V10 计划](../roadmap/host-v10-plugin-compatibility-and-dashboard-plan.md)。

## 规则来源

`build/MyAvaloniaManagement.RuntimeProfile.props` 是共享根、禁带资产和插件引用边界的唯一描述。Host 与 Gate 嵌入它，MSBuild 直接导入它，Build 包携带同一文件。禁带 Newtonsoft.Json 不承诺 Host 提供它；Microsoft.Extensions 的家族禁带与实际运行时闭包也分别表达。

V10 修正了一个旧打包正则漏洞：`Avalonia.dll`、`Ursa.dll` 本身过去可能漏过模式，现与各自子程序集一起禁带。共享加载集合不改变。携带这两个文件的历史错误包需要清除重复共享资产后重新验收；无此资产的冻结旧插件保持原样验证。规则摘要随这项修正变化，旧规则报告不会被当作新规则报告。

## 产物与报告

可选 `plugin.build.json` schema 1 保存目标框架、Build 工具版本及实际解析的 NuGet 依赖。它不扩展 manifest schema 2；旧插件没有该文件时编译包版本显示未知，程序集引用版本单独展示。

插件身份覆盖显式输入的完整、静态部署目录，所有文件都参与；日志、业务数据和报告必须放在独立数据目录。相对路径规范化，拒绝链接、重复和路径逃逸；按路径、长度、内容 SHA-256 排序产生摘要。报告不存入被测目录，避免自引用。

报告 schema 1 包含报告 ID、执行时间、插件 ID / 业务版本 / 产物摘要、Host 文件摘要、规则摘要、环境及分项结果。Host 产品版本和源码标识只辅助阅读；文件身份和运行环境才决定适用性。文件与已加载模块 MVID 不一致时不能确认当前会话身份。

静态、加载组合、Workspace、业务真机四层分别记录。通过、失败、未执行、输入缺失、执行中断不会互相替代。没有报告不是失败，manifest 声明的 SDK 范围也不是已验证范围。

相同插件产物、Host 文件、规则、系统、架构和 .NET 运行时全部匹配，报告才适用于当前环境。导入报告不证明来源经过认证，哈希也不是签名。原始报告不执行命令，不请求网络，不加载附件。

解析限制为 4 MiB、深度 16、1000 个分项、10000 个 Host 文件，拒绝重复字段、未知 schema / 字段 / 枚举及重复场景。存储重复 ID 的同内容导入幂等，不同内容拒绝，原有报告保留。
