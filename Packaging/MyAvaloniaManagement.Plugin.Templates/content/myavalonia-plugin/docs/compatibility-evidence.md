# 插件版本与兼容证据

Host 的“工具 → 插件看板…”提供概览、兼容矩阵和详情与诊断。打开窗口只读状态；要确认验收报告是否适用，点击“检查安装产物”。

插件业务版本、清单 SDK 区间、编译 NuGet 版本及 Host 实际运行版本有不同含义。支持该功能的 Build 会生成可选 `plugin.build.json` 并随 ZIP 交付；旧 Build 没有该文件时，编译依赖显示未知，不代表不能加载。

不要手写或把时间、个人路径放进构建元数据。程序集 AssemblyVersion 单独显示，不能拿它推断 NuGet 包版本。文件内容变化，即使业务版本没变，也属于另一份产物。

Host 维护者可对 ZIP 或冻结目录进行静态、加载组合和显式 Workspace 验收，再交付 `compatibility-report.json`。将报告导入看板后核对适用性。无报告、未执行、失败和报告不匹配是不同状态；加载通过不能证明登录、数据库、下载或原生播放通过。

报告、日志、缓存及业务数据都放在插件代码目录之外。安装内容改变时按部署流程重启 Host；看板不热加载、不安装或更新插件。报告来源没有签名认证，内容哈希只用于确认文件身份。

当前公开 Build 3.4.1 仍保持原内容；只有维护者明确提供的 V10 候选或后续发布包才包含新增元数据生成器。不要把尚未发布的功能当成旧工具已有能力。
