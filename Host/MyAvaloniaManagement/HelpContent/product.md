# 让工具围绕工作展开

MyAvaloniaManagement 是一个模块化桌面工作台。它把窗口、工作区、文件与插件的公共规则交给 Host，让不同业务能力在一个可理解、可管理的空间里协作。

> **当前版本**：产品 {{ProductVersion}} · Plugin SDK {{SdkVersion}}  
> 基础环境：.NET 10、Avalonia 12、Dock 12；当前主要支持 Windows x64。

## 从一个任务开始

当你需要处理一项具体工作时，打开一个 **Document（文档）**。它拥有自己的输入、结果与局部状态。需要查看跨任务的信息时，使用外围的 **Tool（工具面板）**。需要持续执行的工作，则由插件内部的后台服务承担。

| 你要做的事 | 工作台如何支持 |
|---|---|
| 同时处理多个独立任务 | 每个 Document 保留独立的会话和状态 |
| 查看全局任务摘要或文件 | 使用可停靠、可隐藏的 Tool |
| 保持常用工具的位置 | 调整四向 Dock 布局并在正常退出时保存 |
| 延续可保存的工作 | 由对应插件声明内容能力，通过 Host 打开和保存 |
| 增加专业能力 | 安装与 SDK 兼容的内部可信 Managed Plugin |

## 一个可以逐步熟悉的空间

中央区域承载当前任务，外围区域提供导航和状态。你可以调整面板比例、停靠方向和可见性，让频繁一起使用的信息靠近。下面的演示使用独立的示例数据，你可以放心操作。

## 能力边界

- Host 提供工作台基础能力，业务功能取决于实际安装并成功初始化的插件。
- Document 能否保存，由该文档类型是否实现持久化能力决定。
- 布局保存的是空间结构与工具状态；它不等同于自动保存全部业务内容或重开历史文档。
- 当前插件属于同进程、内部可信模型。替换插件需要退出 Host、更新文件并重新启动。
