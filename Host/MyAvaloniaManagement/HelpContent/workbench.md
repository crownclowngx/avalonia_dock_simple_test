# 从任务到工作区

从欢迎页“开始使用”或“文件 → 功能中心…”选择功能，在独立标签中开始工作。辅助工具通过“工具 → 工具中心…”按需显示。

## 页面：一次具体的工作

选择功能并点击“打开”新建页面，或使用 **文件 → 打开…** 恢复已有文件。多个同类文档可以同时存在，每个实例拥有独立状态和资源作用域。

对于支持持久化的活动文档，使用 **文件 → 保存** 或 `Ctrl+S`。Host 负责文件路径、原子提交和保存后的状态更新，插件负责捕获自身业务内容。保存失败时应根据界面反馈处理，避免把未完成的提交当成已经保存。

## 工具：跨页面使用的辅助入口

工具面板用于文件导航、插件分组菜单等跨任务信息。它们通常是单例，均可隐藏，并可通过“工具 → 工具中心…”重新显示。工具标题栏 × 表示隐藏；隐藏保留当前状态，不停止后台任务。每行的“⋯”提供隐藏、分类和常用排序；“整理工具”可管理分类或隐藏整个工作区的工具。

“工具 → 插件状态…”打开独立非模态窗口，查看本次会话的插件概览、兼容性、贡献信息和诊断记录。搜索、状态筛选和复制诊断均在窗口内完成，不占用 Dock 工具位置。

## Dock：安排信息的位置

将相关工具安排在左、右、上、下区域，拖动分隔线调整比例。当前工作区禁止 Dock 浮动；帮助中心本身是 Host 管理的独立窗口。

布局使用严格的 Layout V2 格式。布局文件无效或引用不可用插件时，宿主会隔离快照并恢复默认布局。布局只维护空间结构，不保存密码、业务表单和 Document 内容。

## 常用操作

| 操作 | 入口 |
|---|---|
| 打开已保存文档 | 文件 → 打开… |
| 保存当前可持久化文档 | 文件 → 保存 / `Ctrl+S` |
| 查找功能、已有页面、工具或命令 | `Ctrl+Shift+P` |
| 在新标签中开始工作 | 欢迎页“开始使用” / 文件 → 功能中心… |
| 查看帮助 | 帮助 → 帮助中心 / `F1` |
| 切换外观 | 视图 → 主题 |
| 查找帮助正文 | 在帮助窗口按 `Ctrl+F` |

## 使用工作区搜索

按 `Ctrl+Shift+P`，搜索名称、说明或来源。结果右侧标明动作：“打开新标签”“切换到页面”“显示／定位”或“执行命令”。同名页面用来源和本次运行的页面序号区分；切换保留页面内容与未保存修改。

名称精确、前缀、包含匹配依次优先，说明匹配排在后面。方向键选择，Enter 或双击执行，Esc 关闭空闲搜索并回到原位置。打开期间等待初始化完成；失败保留查询、选择和错误，可直接重试。页面已经关闭或插件不可用时不会用同名结果替代。

工具中心搜索会跨用途分类，但保留显式来源筛选；可点击“清除来源”。清空搜索恢复原导航位置。当前页面列表只涵盖本次运行，布局记忆不等于业务内容已保存。

## 关闭与退出

有未保存内容时，关闭文档或退出主窗口可能出现保存确认。取消关闭后，原有工作和帮助窗口继续保留。主窗口真正退出后，Host 会关闭帮助并按所有权顺序释放工作区和插件资源。

## 帮助的阅读方式

左侧切换章节，顶部前进和后退返回阅读历史。字号按钮适合长文阅读；“减少动画”保留静态图与分步讲解。理论正文默认折叠，点击“完整正文与参考文献”深入阅读。搜索可直接定位折叠正文里的内容。
