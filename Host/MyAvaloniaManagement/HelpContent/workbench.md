# 从任务到工作区

工作台通过 **Document、Tool 与后台服务**分配不同的责任。熟悉这三个概念后，多窗口和可停靠布局会更容易理解。

## Document：一次具体的工作

通过插件菜单创建文档，或使用 **文件 → 打开…** 恢复已有文件。多个同类文档可以同时存在，每个实例拥有独立状态和资源作用域。

对于支持持久化的活动文档，使用 **文件 → 保存** 或 `Ctrl+S`。Host 负责文件路径、原子提交和保存后的状态更新，插件负责捕获自身业务内容。保存失败时应根据界面反馈处理，避免把未完成的提交当成已经保存。

## Tool：持续可见的摘要与入口

工具面板用于文件导航、插件分组菜单等跨任务信息。它们通常是单例，均可隐藏，并可通过“工具 → 工具中心…”重新显示。

“工具 → 插件状态…”打开独立非模态窗口，查看本次会话的插件概览、兼容性、贡献信息和诊断记录。搜索、状态筛选和复制诊断均在窗口内完成，不占用 Dock 工具位置。

## Dock：安排信息的位置

将相关工具安排在左、右、上、下区域，拖动分隔线调整比例。当前工作区禁止 Dock 浮动；帮助中心本身是 Host 管理的独立窗口。

布局使用严格的 Layout V2 格式。布局文件无效或引用不可用插件时，宿主会隔离快照并恢复默认布局。布局只维护空间结构，不保存密码、业务表单和 Document 内容。

## 常用操作

| 操作 | 入口 |
|---|---|
| 打开已保存文档 | 文件 → 打开… |
| 保存当前可持久化文档 | 文件 → 保存 / `Ctrl+S` |
| 查找工作台命令 | `Ctrl+Shift+P` |
| 查看帮助 | 帮助 → 帮助中心 / `F1` |
| 切换外观 | 视图 → 主题 |
| 查找帮助正文 | 在帮助窗口按 `Ctrl+F` |

## 关闭与退出

有未保存内容时，关闭文档或退出主窗口可能出现保存确认。取消关闭后，原有工作和帮助窗口继续保留。主窗口真正退出后，Host 会关闭帮助并按所有权顺序释放工作区和插件资源。

## 帮助的阅读方式

左侧切换章节，顶部前进和后退返回阅读历史。字号按钮适合长文阅读；“减少动画”保留静态图与分步讲解。理论正文默认折叠，点击“完整正文与参考文献”深入阅读。搜索可直接定位折叠正文里的内容。
